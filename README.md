# 📚 EduCheck - 공부방 맞춤형 모바일 스마트 출석관리 시스템

초·중·고등학생 대상의 공부방처럼 **수업 시간이 일정하지 않고 변동이 잦은 환경**을 위해 개발된 **모바일 최적화 웹 출석관리 프로그램**입니다.

---

## 🌟 주요 특징 및 장점

1. **유동적인 수업시간 완벽 대응 (실시간 입·퇴실 & 체류시간 자동 계산)**
   - 정해진 시간표가 없어도 학생이 올 때 **[입실]**, 갈 때 **[퇴실]** 원터치로 체크하면 실제 공부방에서 학습한 시간(예: 2시간 45분)이 자동으로 정확히 집계됩니다.
   - 현재 공부방에 있는 학생(재실 현황)을 상단 대시보드에서 실시간으로 확인할 수 있습니다.

2. **학생 개인별 출석부 & 요일·시간 스케줄(시간표) 관리 [신규]**
   - 학생마다 **"월요일 14:00 (오후 2시), 화요일 16:00 (오후 4시)"** 등 정규 수업 스케줄을 손쉽게 설정하고 관리할 수 있습니다.
   - 학생별 **월간 출석 캘린더** 및 일자별 출결 타임라인을 통해 정규 스케줄 대비 실제 출석 현황을 한눈에 파악하고, 날짜별 출결을 원클릭으로 수정할 수 있습니다.
   - 학생 개인별 **월간 출석부 엑셀(.xlsx)** 다운로드를 지원하여 학부모 발송 및 보관이 용이합니다.

3. **모바일 퍼스트(Mobile-First) 디자인**
   - 스마트폰에서 한 손으로 쉽게 조작할 수 있는 직관적인 하단 탭바와 시원한 UI를 제공합니다.
   - 반응형 디자인으로 스마트폰, 태블릿, PC 어디서든 최적의 화면으로 동작합니다.

4. **학생 셀프 출석 체크 (키오스크 모드)**
   - 공부방 입구에 태블릿이나 스마트폰을 거치해두고 **[셀프출석]** 탭을 켜두면, 학생이 본인 전화번호 뒷자리 4자리를 눌러 스스로 입실/퇴실을 찍을 수 있습니다.

5. **학부모 안심 알림 문자 / 카카오톡 연동**
   - 입실/퇴실 시 "[공부방] OOO 학생이 17:05에 등원했습니다." / "20:30에 하원했습니다 (총 학습: 3시간 25분)" 문구를 원터치로 복사하거나 문자 앱으로 바로 전송할 수 있습니다.

6. **엑셀(Excel) 완벽 연동**
   - **일간 출석부 다운로드**: 선택한 날짜의 전체 출결 현황을 `.xlsx` 파일로 저장.
   - **월간 종합 리포트 다운로드**: 월별 출석 일수, 지각 횟수, 총 학습시간 통계표를 엑셀로 저장.
   - **개인별 출석부 엑셀 다운로드**: 학생별 1달간의 상세 출결 기록 엑셀 파일 저장.
   - **학생 명단 엑셀 일괄 등록**: 기존에 보유한 엑셀 명단을 양식에 맞춰 한 번에 업로드 가능.

7. **간단 비밀번호 로그인 & 화면 잠금 보안 [신규]**
   - 학생 개인정보 및 출결 기록 보호를 위해 **원터치 비밀번호(PIN) 잠금 및 로그인 기능**을 제공합니다.
   - 상단 헤더의 자물쇠 버튼으로 언제든 화면을 즉시 잠글 수 있으며, [통계·엑셀] 탭에서 비밀번호 설정/변경/해제가 가능합니다.
   - 키오스크(셀프 출석) 화면과 관리자 화면이 분리되어, 학생들이 출석을 찍는 동안에도 관리자 메뉴는 안전하게 보호됩니다.

8. **설치 필요 없음 & 안전한 로컬 저장**
   - 웹 브라우저 로컬 저장소(LocalStorage)에 데이터가 안전하게 보관되며, 서버 설정 없이도 즉시 실행됩니다.
   - [전체 백업 (JSON)] 및 [백업 복원] 기능을 통해 데이터를 영구히 안전하게 관리할 수 있습니다.

## 📱 스마트폰에서 앱처럼 사용하는 방법 (홈 화면 추가)

### 🍎 iPhone / iPad (Safari)
1. Safari 브라우저에서 본 프로그램을 엽니다.
2. 화면 하단 중앙의 **공유 버튼(네모에 위쪽 화살표 모양)**을 터치합니다.
3. 메뉴 중 **[홈 화면에 추가]**를 선택합니다.
4. 스마트폰 홈 화면에 생성된 '공부방 출석관리' 아이콘을 누르면 앱처럼 전체 화면으로 실행됩니다.

### 🤖 Android 스마트폰 / Galaxy (Chrome / Samsung Internet)
1. Chrome 브라우저에서 본 프로그램을 엽니다.
2. 우측 상단의 **더보기 메뉴(점 3개)**를 터치합니다.
3. **[홈 화면에 추가]** 또는 **[앱 설치]**를 선택합니다.

## 🚀 실행 방법

- **방법 1 (간단 실행)**: `index.html` 또는 `공부방_출석관리_모바일.html` 파일을 더블 클릭하여 크롬이나 사파리 브라우저에서 바로 실행합니다.
- **방법 2 (로컬 웹서버 실행 - 스마트폰 Wi-Fi 연동 시)**:
  터미널에서 해당 폴더로 이동 후 아래 명령어를 실행하면 같은 Wi-Fi에 연결된 스마트폰에서도 접속할 수 있습니다:
  ```bash
  python3 -m http.server 8080
  ```
  스마트폰 브라우저에서 `http://[컴퓨터IP주소]:8080` 으로 접속합니다.
